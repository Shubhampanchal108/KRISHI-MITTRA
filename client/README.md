# 🌾 Krishi Mittra Mobile Application Client

This is the React Native (Expo) mobile frontend for **Krishi Mittra** — an AI-powered agricultural ecosystem for precision farming.

For complete project documentation, system architecture, API endpoints, and setup instructions, please see the main **[Project README](../Readme.md)**.

## 🚀 Quick Start (Client)

1. **Install dependencies:**
   ```bash
   npm install
   ```

2. **Start the Expo server:**
   ```bash
   npx expo start
   ```

3. **Run on device or emulator:**
   - Scan the QR code using **Expo Go** (Android/iOS)
   - Press `a` for Android Emulator
   - Press `i` for iOS Simulator
   - Press `w` for Web preview

## 📱 Key Client Features
- **Animated Launch Screen:** High-performance React Native animated splash screen (`SplashScreen.jsx`).
- **AI Chatbot & Pest Scanner:** Interactive chat interface & camera image uploading.
- **N-P-K Soil Calculator:** Form inputs and interactive fertilizer charts.
- **Live Mandi Prices & Weather:** Real-time location-aware cards and advice.
