# 🌾 Krishi-Mittra — Smart Farming Assistant

Krishi-Mittra is an **AI-powered, multilingual mobile application** that provides farmers with real-time, location-based agricultural advisory.  
It empowers farmers by offering soil health analysis, fertilizer guidance, pest detection, and AI-driven crop recommendations — all in their local language and with voice support.

---

## 🚀 Features

- 🌍 **Multilingual AI Chatbot:** Real-time, region-specific crop advisory in multiple languages.  
- 🧠 **AI-Powered Recommendations:** Personalized suggestions using an open-source LLM model.  
- 🌱 **Soil Health Analysis:** Smart fertilizer and soil management guidance.  
- 🐛 **Pest & Disease Detection:** Upload images to detect plant diseases instantly using AI.  
- 🎙️ **Voice Interaction:** Voice-based support for low-literate users.  
- 📊 **Feedback System:** Collects user feedback for continuous improvement.  
- 📡 **Live Streaming:** Powered by Gemini Live API for real-time expert sessions and field monitoring.  
- ☁️ **External Integrations:** Weather and Market APIs for instant, accurate data.

---

## 🧩 Tech Stack

### **Frontend (Mobile App)**
- **React Native** — Cross-platform mobile development for Android & iOS.  
- **Tailwind CSS / NativeWind** — For fast and responsive styling.  
- **Expo** — For quick deployment and testing.  

### **Backend (Server)**
- **Node.js & Express.js** — RESTful API backend.  
- **MongoDB (Mongoose)** — NoSQL database for scalable data storage.  

### **AI & Integrations**
- **Open-Source LLM Model** — For AI advisory and multilingual response generation.  
- **Gemini Live API** — Enables live video and data streaming.  
- **External APIs:**  
  - Weather API 🌦️  
  - Agmarknet API 💰

## ⚙️ Installation & Setup

1. **Clone the Repository**
   ```bash
   git clone https://github.com/Shubhampanchal108/KRISHI-MITTRA.git
   cd Krishi-Mittra
````

2. **Install Dependencies**

   ```bash
   npm install
   cd client && npm install
   ```

3. **Start Backend Server**

   ```bash
   npm run server
   ```

4. **Run Mobile App**

   ```bash
   cd client
   npm start
   ```
