Executive Summary & Core Mission

Modern agriculture faces severe challenges including unpredictable climate shifts, crop pest outbreaks, soil nutrient depletion, and opaque market pricing. Krishi Mittra unifies Vision AI plant diagnostics, N-P-K soil health analysis, live Agmarknet mandi prices, voice-assisted multilingual AI chatbots, and micro-climate weather advisories into a seamless mobile experience.

Mission Statement: "To democratize artificial intelligence for every farmer, transforming traditional agriculture into precision, sustainable, and profitable smart farming."

REST API Reference

Complete endpoint breakdown for integration with mobile clients and external services.

POST /api/signup
Registers a new farmer account into the database with password hashing.
Request Body (JSON) 
{
  "name": "Ramesh Kumar",
  "email": "ramesh.farmer@gmail.com",
  "password": "SecurePassword123",
  "state": "Punjab",
  "district": "Ludhiana"
}
POST /api/login
Authenticates farmer credentials and returns a signed JSON Web Token (JWT).
POST /api/soil/add
Stores soil N-P-K profile sample and returns recommended fertilizer dosage.
Payload Example 
{
  "userId": "65f8a92b3c4d1e2f3a4b5c6d",
  "nitrogen": 140,
  "phosphorus": 45,
  "potassium": 50,
  "ph": 6.8,
  "cropType": "Wheat"
}
POST /api/pest/scan
Uploads crop leaf image via Multer multipart and processes instant Groq Vision AI diagnosis.
cURL Request 
curl -X POST http://localhost:5000/api/pest/scan \
  -H "Authorization: Bearer YOUR_JWT_TOKEN" \
  -F "image=@/path/to/infected_leaf.jpg" \
  -F "userId=65f8a92b3c4d1e2f3a4b5c6d"
POST /api/chat/add
Sends user query to Krishi Bot Groq LLM and saves conversation history in MongoDB.

Installation & Local Setup

Follow this step-by-step guide to clone, install, and run Krishi Mittra locally.

1
Clone Repository

Clone the GitHub repository to your local machine.

Terminal 
git clone https://github.com/Shubhampanchal108/KRISHI-MITTRA.git
cd KRISHI-MITTRA
2
Configure & Start Backend Server

Navigate to the Server folder, install dependencies, and start Express server.

Terminal 
cd Server
npm install
npm start
3
Configure & Launch Expo Mobile Client

Open a new terminal window, navigate to the client folder, and start Expo dev server.

Terminal 
cd client
npm install
npx expo start

Environment Configuration

Create a .env file in the Server/ directory with the following variables:

Server/.env 
PORT=5000
MONGO_URI=mongodb+srv://your_username:your_password@cluster.mongodb.net/krishimittra
GROQ_API_KEY=gsk_your_groq_api_key_here
JWT_SECRET=your_jwt_secret_key_here

FAQ & Troubleshooting

Frequently asked questions regarding setup, AI diagnostics, and app usage.

How does the AI Pest Diagnostic scanner identify diseases?
When you capture a leaf photo, it is uploaded securely to the Express backend and evaluated using Groq Llama-3 Vision models trained on thousands of plant pathology datasets.
Is an internet connection required to use Krishi Mittra?
Active AI chat and live Mandi prices require an internet connection. However, recent soil health records and downloaded government scheme guides remain accessible offline via Async Storage.
How do I replace the dummy APK link with my actual compiled APK?
Place your compiled .apk binary into Documentation/assets/krishi-mittra-v1.0.apk or update the download-apk-trigger event handler in script.js.
